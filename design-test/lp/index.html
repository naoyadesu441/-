配達のしくみ

毎朝、決まった時刻に同じ手順で動きます。人の手を待たないので、休みの日も届きます。

  1. 08:00

    集める・裏取りする

    無料の情報源から海外のAIニュースを集め、重複を除き、発表元の一次情報までたどれるかを判定します。

    GitHub Actions
  2. 08:00台

    要約して届ける

    一次情報が確認できたものだけを日本語で要約し、元リンクを添えて一通にします。Discordに通知し、Notionにも蓄積します。

    Gemini 無料枠・Discord・Notion
  3. 09:00

    台本にする

    その日の便から、YouTube動画とThreads投稿の台本を書き起こします。届いたニュースがそのまま発信の材料になります。

    Claude Code のルーティン

消印が押されるニュース、押されないニュース

速さより確かさを優先します。基準は一つ、発表元の一次情報までたどれるかどうかです。

便に入るもの

企業の公式ブログ、公式発表、論文など、発表元そのものにリンクできるニュース。要約の下に、必ずその元リンクを置きます。

便に入らないもの

まとめ記事やSNSの噂だけで、発表元までたどれないニュース。話題になっていても、裏取りできるまでは届けません。
